# Cerio

A 2D platformer (in the style of Mario / Celeste) with a bot that autonomously completes procedurally generated levels.

## Project goals

- Game: reach the level exit, avoid obstacles, wall climbing, stamina, buttons.
- Bot: runs inside the game on metadata (no rendering), using an algorithm or a trained model.
- Criteria: ≥ 70% of the 10 test levels completed, in less than 3× human completion time.

## Stack

Python, Pygame, PyTorch
